Quiero crear una página web profesional para mi negocio de diseño web llamado Zunexa Web.

IMPORTANTE:
Quiero que sea una página web profesional, moderna, elegante y orientada a conseguir clientes reales.

La web debe estar diseñada MOBILE FIRST y funcionar perfectamente en teléfonos móviles, tablets y ordenadores.

ESTILO:
- Fondo oscuro premium.
- Colores principales azul eléctrico y violeta.
- Detalles luminosos pero elegantes.
- Tipografía moderna y muy legible.
- Diseño limpio, profesional y tecnológico.
- Animaciones suaves, sin exagerar.
- Excelente contraste y legibilidad.
- No quiero una web genérica.
